ON THIS DISC (folder SOURCE)
  RUDOLF.TXZ    Rudolf OS: desktop modules, Rudolf Boot loader, rudolfd,
                rudolf-display, init scripts, kernel configuration script and
                every build script used to make this disc (GPL-2.0-or-later).
  BUSYBOX.TXZ   BusyBox 1.36.1, unmodified (GPL-2.0).
  WIFI.TXZ      wpa_supplicant/hostapd 2.12-devel (BSD-3-Clause, with the small
                changes in wifibuild.sh applied) and libnl 3.9.0 (LGPL-2.1),
                as built into wpa_supplicant and wpa_cli.
  BUSYBOX.CFG   The BusyBox build configuration used.
  LINUX.CFG     The Linux kernel build configuration used.
  PACKAGES.TXT  Every Ubuntu 24.04 binary package that files on this disc were
                taken from, with its exact version and source package.
