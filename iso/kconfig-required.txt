# The kernel features Rudolf OS's programs and security rely on (docs/plan-1.6.1.md Part 12, "First, before any tuning is
# merged"): iso/systools/kreq.sh stops the kernel's build when one is missing after kconfig.sh, with its name and who needs
# it, so a tuning change that drops one never reaches a computer. A line: OPTION  y|m|ym  GROUP: WHO NEEDS IT
# (ym: built in or a module). Checked against Linux 6.18 as configured by kconfig.sh (x86-64).
# -- Flatpak and bubblewrap (Linux apps' sandboxes; Debian's and the desktop's own sandboxes use them too)

PID_NS          y   flatpak: bubblewrap's PID namespace (--unshare-pid)
NET_NS          y   flatpak: bubblewrap's network namespace (--unshare-net, apps without network)
IPC_NS          y   flatpak: bubblewrap's IPC namespace (--unshare-ipc)
UTS_NS          y   flatpak: bubblewrap's UTS namespace (--unshare-uts)
SECCOMP         y   flatpak: Flatpak's system-call filter
SECCOMP_FILTER  y   flatpak: Flatpak's system-call filter (BPF)
OVERLAY_FS      y   flatpak: the system's own layers (overlayfs), and Flatpak's runtime extensions
FUSE_FS         ym  flatpak: the document portal (xdg-document-portal) and AppImages
FHANDLE         y   flatpak: name_to_handle_at (the document portal, udev)
# -- The Debian container, Wine and Steam

INPUT_EVDEV     y   desktop: input devices (rudolf-display, Xorg's evdev)
